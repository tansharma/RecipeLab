# RecipeLab

The public site for **RecipeLab** — a curated reference for Fujifilm camera
settings shaped by analogue photography.

This repo holds only the static site (landing page, features, FAQ, privacy
policy, support). It is a **mirror**, published from a private source repo —
this is not where the site is edited. See `privacy.html` and `support.html`
for the pages App Store Connect requires.

Once GitHub Pages is enabled (Settings → Pages → Deploy from a branch → `main`,
`/` root), the site is served at the repo's Pages URL.

Not affiliated with, endorsed by, or sponsored by Fujifilm or any third-party
camera and film manufacturer mentioned on this site.
